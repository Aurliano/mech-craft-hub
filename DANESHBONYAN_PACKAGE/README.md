# پکیج مستندات دانش‌بنیان - MechCraft Hub

## 📋 فهرست مستندات

این پکیج شامل تمام مستندات مورد نیاز برای درخواست دانش‌بنیان است.

### 📁 ساختار پوشه‌ها

- **COMPANY_DOCUMENTS/**: مدارک شرکت (روزنامه رسمی، شناسه ملی، اساس‌نامه)
- **PRODUCT_DOSSIER/**: معرفی محصول، توضیح فنی، نوآوری‌ها
- **ARCHITECTURE/**: ERD، معماری سیستم، نمودارها
- **RND/**: گزارش تحقیق و توسعه، دفترچه توسعه
- **PILOT/**: نتایج آزمایش‌های pilot، فیدبک کاربران
- **SECURITY/**: گزارش‌های امنیتی، تست‌های امنیت
- **CODE/**: لینک repository، گزارش‌های CI/CD
- **BUSINESS/**: برنامه تجاری، تحلیل رقبا، مدل درآمد
- **TEAM/**: رزومه اعضای تیم، ساختار تیم
- **LEGAL/**: قراردادها، سیاست‌ها، مجوزها
